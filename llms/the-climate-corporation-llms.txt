# The Climate Corporation (Climate FieldView Platform)

> The Climate Corporation (Climate LLC, a Bayer company) operates Climate FieldView, one of the largest digital agriculture platforms, covering 120M+ acres. The FieldView Platform APIs let partners read and write growers' field boundaries, agronomic layers (as-planted, as-applied, as-harvested), scouting observations, farm organizations, and operations, and run bulk uploads and exports — all with the grower's OAuth2 consent.

Base URL: https://platform.climate.com (v4; e.g. https://platform.climate.com/v4/fields). Auth: OAuth2 authorization_code bearer token (token endpoint https://api.climate.com/api/oauth/token) PLUS a required X-Api-Key header on every call. A v5 surface is in preview.

## APIs
- [Climate FieldView Platform API (v4)](https://dev.fieldview.com/technical-documentation/): Fields, Boundaries, Uploads, Exports, Layers, ResourceOwners, FarmOrganizations, Operations.
- [Next API Versions (v5 preview)](https://dev.fieldview.com/technical-documentation/next-versions/): fields, enrollments, experiments, connections, growing seasons, planting/harvest/application reports, prescription exports.
